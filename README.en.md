# MT5 Manager — manage many MT5 accounts from one screen · FREE

**MT5 Manager** is a Windows tool to monitor and control **many MetaTrader 5 accounts at once**: one dashboard for every balance, equity, P/L and open position; batch orders; copy trading between accounts; automatic money management; and remote control from your phone.

> 🎁 **Free for the community** — register a tradingauto.org account and you're in, **no license key needed**.

## ✨ Features

**📊 One dashboard for everything**
- Balance, equity, P/L and open positions of every account — refreshed about every second.
- No limit on the number of MT5 accounts. The app clones a terminal for each account and runs it hidden.
- See at a glance which EA is attached, on which symbol and timeframe, for every account.

**🎯 Order management**
- Place orders on many accounts at once.
- Partial close (magic number and comment kept), set SL/TP by price or by money amount.
- Automatic break-even and trailing stop.
- Quick filters by profit / loss, symbol, magic.

**🔁 Internal copy trading**
- One source account → many target accounts on the same machine, even **across brokers** (symbol names matched automatically).
- Cross-machine copying between several computers running MT5 Manager.

**🛡️ Money management**
- Daily loss limit, drawdown from peak, margin level.
- Three responses: alert only · close all positions · close all and disable the account. Full activity log.

**🤖 EAs & bundled tools**
- Attach an EA to many accounts in one go (symbol, timeframe, settings file).
- The tradingauto.org tool store (Smart DCA, TradePanel…) comes preinstalled in every terminal and updates itself.
- **Edit MT5 settings** button to keep WebRequest URLs, EA permissions… across restarts.

**📡 Signals**
- **TradingView → MT5**: TradingView alerts become trades automatically; build the alert message right inside the app.
- **VIPTREND**: receive signals by channel.
- Demo accounts and accounts on the IB list use them for free with the key `vipmember`.

**📱 Remote control**
- Your own dashboard at `service.tradingauto.org/<your-name>` — open it from your phone anywhere, no router port forwarding.
- Layered security: your own password, 2-step verification (Google Authenticator), a **view-only** password to share with followers, automatic blocking of IPs guessing passwords, auto sign-out when idle.
- **Trusted devices**: your own computer / phone gets straight in without typing the password; every sign-in is reported on Telegram.

**📈 Statistics & alerts**
- P/L by day, month and weekday; cumulative chart; CSV export.
- Telegram alerts sent straight from your own machine.

## 💻 Requirements

- Windows 10 / 11 (Windows Server 2012 R2 or later also works).
- MetaTrader 5 installed on the machine — MT5 Manager drives the real terminal, it does not replace it.
- The machine must stay on and online for the app to work (use a Windows VPS to run 24/7).

## 🔄 Updates

The app tells you when a new version is out — one click downloads and installs it. Update packages are digitally signed, so the app only accepts official builds.
The `MT5Manager-<version>-update.zip` files in Releases are for the auto-update mechanism — new users should download the **`-setup.zip`** file.
